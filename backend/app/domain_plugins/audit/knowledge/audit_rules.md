# 财务交易审计规则手册

## 1. 重复付款

同一供应商（优先供应商编码，其次规范化供应商名称）在金额相同的前提下，如果发票号相同或付款单号相同，首条记录视为正常，其余记录标记为重复付款。复核时应核对合同、发票与付款申请，确认是否为重复入账或拆单。

## 2. 大额交易

交易金额大于等于阈值（默认 100000 元）的交易为高风险大额交易。审计人员应核对合同金额、验收单、审批链和银行回单；阈值可按项目风险调整。

## 3. 短期重复付款

同一供应商在窗口期（默认 7 天）内出现 3 笔及以上付款时，第 3 笔及之后的付款标记为短期重复付款。该规则用于识别拆单、重复采购和异常资金流出，需结合业务背景复核。

## 4. 数据质量问题

缺少交易日期、供应商、金额或付款单号的记录，负数金额，无法解析的金额，以及重复的付款单号都属于数据质量问题。数据质量问题必须与业务异常分开报告，避免将数据缺陷误判为舞弊。

## 5. 报告与引用

报告必须按行号排序并引用原始交易记录。每条异常应包含规则、风险等级、行号、交易编号、供应商、金额、日期、摘要与证据字段。报告仅供审计复核参考，不替代人工职业判断。

## 6. 供应商与付款字段

标准字段包括：交易日期、供应商、供应商编码、金额、付款单号、发票号、摘要、部门、银行账号。解析时应保留原始行号，字段映射结果应在报告中说明。
